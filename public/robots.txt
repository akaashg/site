# Everything on this site is public and meant to be read, by people and by
# machines. The wildcard group below already permits every AI crawler; the
# named groups exist because a blanket "Allow: /" is indistinguishable from
# nobody having thought about it, and some operators check for their own token.
#
# Note the matching rule: a crawler that finds its own User-agent group ignores
# the "*" group entirely, so each group below has to repeat "Allow: /".
#
# To opt out of AI use later, change the relevant Allow to Disallow. Removing
# the group is not enough -- it would fall back to the permissive wildcard.
