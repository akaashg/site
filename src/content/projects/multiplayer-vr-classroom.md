This unpublished training prototype focused on 3 core requirements: instructor-led guidance, sequenced task flow, and synchronized multi-user interactions. It uses Unity, Photon Fusion, XR Interaction Toolkit, and Meta Quest as a reusable foundation for clinical, industrial, and education simulations.

## Outcome

Built a 3-part guided-training foundation: instructor control, task sequencing, and shared multiplayer state. This project remains a draft because no public client, pilot, or trainee metrics are available to publish.
